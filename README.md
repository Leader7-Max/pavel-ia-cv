# 📝 Pavel IA CV

**Pavel IA CV** est une application web moderne, simple et 100 % gratuite conçue pour aider les chercheurs d'emploi et professionnels à rédiger rapidement des CV et lettres de motivation percutants grâce à l'intelligence artificielle.

---

### ✨ Fonctionnalités clés
- **Génération sur-mesure** : Rédaction automatisée de CV et lettres de motivation adaptée au poste visé et à l'entreprise.
- **Moteur IA puissant** : Utilise le modèle `gemini-2.5-flash` via l'API Google Gemini pour des textes fluides et professionnels.
- **Export PDF direct** : Téléchargement immédiat du document généré au format PDF en un clic.
- **100 % Gratuit & Responsive** : Conçu pour fonctionner aussi bien sur smartphone que sur ordinateur, sans frais d'hébergement.

---

### 🛠️ Technologies utilisées
- **Frontend / UI** : [Streamlit](https://streamlit.io/) (Python)
- **IA / LLM** : [Google Gemini API](https://aistudio.google.com/) (`google-genai`)
- **Génération PDF** : [FPDF](https://pyfpdf.readthedocs.io/)
- **Hébergement** : Streamlit Community Cloud

---

### 🚀 Comment utiliser l'application ?
1. Récupère une clé API gratuite sur [Google AI Studio](https://aistudio.google.com/).
2. Saisis ta clé API dans la barre latérale de l'application.
3. Remplis les informations de ton parcours et les consignes particulières.
4. Clique sur **🚀 Générer le document** et télécharge ton fichier PDF.
